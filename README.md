      <p style="font-family: monospace; font-size: 14px; background: #0B0B0C; color: #FBF7F4; padding: 15px; border-radius: 6px; overflow-x: auto;">
        Browser Client ──► Next.js 16 (Vercel) ──► Express 5 REST API (Linux VPS / Render) ──► MongoDB Atlas 8.3

      <ul>
        <li><b>Proxy Router (<code>proxy.ts</code>):</b> Inspects authentication tokens on protected routes. Unauthenticated traffic redirects cleanly before rendering.</li>
        <li><b>Zero Data Route Handlers:</b> Next.js rewrites all <code>/api/:path*</code> calls directly to the Express target. Express remains the single persistence boundary.</li>
        <li><b>Isolated Cache Invalidation:</b> The only Next.js internal route handler is <code>/api/revalidate</code>, which receives webhook calls to purge storefront cache tags.</li>
      </ul>

    <td style="padding: 20px;">
      <h3 style="color:#974822; margin-top: 0;">💳 1. Payment Verification</h3>
      <p>Cash-on-delivery orders in Bangladesh often suffer from fake numbers and return fraud. MINAN solves this at the checkout level.</p>
      <ul>
        <li><b>Advance Delivery Fee Verification:</b> Customers can pay the full amount through bKash, or pay a mandatory non-refundable delivery fee in advance while paying merchandise through COD.</li>
        <li><b>Tokenized bKash Integration:</b> Uses secure grant token rotation. Credentials remain hidden from client bundles.</li>
        <li><b>Atomic Order Allocation:</b> Generates unique sequential order numbers (<code>MN-YYYYMMDD-####</code>) using daily counters in MongoDB.</li>
        <li><b>Idempotency Guarantees:</b> Prevents duplicate orders and duplicate payment settlements through unique checkout hashes.</li>
      </ul>
    </td>
  </tr>

        <li><b>Speculation Rules API:</b> Prerenders catalog and collection documents on user hover or viewport intent, delivering near-instant page transitions.</li>

### Prerequisites

- **Node.js:** `24.16.0`
- **Package Manager:** `npm` (workspace support)
- **Database:** MongoDB Atlas account or local MongoDB 8.x instance
- **Image Storage:** Cloudinary account for signed uploads

### Installation and Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/IshakQuresheeAkib/minan.git
   cd minan
   ```

2. **Install monorepo dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   - Copy the example templates:
     ```bash
     cp apps/web/.env.example apps/web/.env.local
     cp apps/api/.env.example apps/api/.env
     ```
   - Essential frontend keys in `apps/web/.env.local`:
     ```env
     API_PROXY_TARGET=http://localhost:3001
     NEXT_PUBLIC_SITE_URL=http://localhost:3000
     JWT_ACCESS_SECRET=replace_with_min_32_char_secret_access
     ```
   - Essential backend keys in `apps/api/.env`:
     ```env
     PORT=3001
     MONGODB_URI=mongodb://localhost:27017/minan
     JWT_ACCESS_SECRET=replace_with_min_32_char_secret_access
     JWT_REFRESH_SECRET=replace_with_min_32_char_secret_refresh
     CUSTOMER_JWT_ACCESS_SECRET=replace_with_min_32_char_customer_access
     CUSTOMER_JWT_REFRESH_SECRET=replace_with_min_32_char_customer_refresh
     ADMIN_EMAIL=admin@minan.com
     ADMIN_PASSWORD=replace_with_secure_admin_password
     BKASH_BASE_URL=https://tokenized.sandbox.bka.sh/v2
     BKASH_APP_KEY=your_bkash_key
     BKASH_APP_SECRET=your_bkash_secret
     BKASH_USERNAME=your_bkash_username
     BKASH_PASSWORD=your_bkash_password
     DELIVERY_FEE_INSIDE_SYLHET_BDT=60
     DELIVERY_FEE_OUTSIDE_SYLHET_BDT=120
     API_PUBLIC_URL=http://localhost:3001
     FRONTEND_URL=http://localhost:3000
     ```
     *(See `apps/api/.env.example` and `apps/web/.env.example` for the full reference).*

4. **Seed database data:**
   ```bash
   npm --workspace @minan/api run seed
   npm --workspace @minan/api run seed:admin
   npm --workspace @minan/api run seed:home-banners
   ```

5. **Start development servers:**
   ```bash
   # Terminal 1: Run Next.js storefront (Turbopack)
   npm run dev:web

   # Terminal 2: Run Express API (tsx watch)
   npm run dev:api
   ```

6. **Run test suites:**
   ```bash
   npm run test
   ```
